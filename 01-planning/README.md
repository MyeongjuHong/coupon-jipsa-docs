## 🎯 주요 내용 요약

### 프로젝트 개요

- **프로젝트명**: 쿠폰집사
- **목표**: 가족/지인이 기프티콘을 안전하게 등록·공유하고 만료 알림을 받는 웹 서비스
- **타겟 사용자**: 가족 5명, 비개발자 포함

### 핵심 기능 (Must)

- 카카오 OAuth 단일 인증
- 스페이스 생성 및 초대 (링크 기반, 24h, 1회성, 방장 승인)
- 쿠폰 등록 (수동 입력) 및 만료순 정렬
- 만료 7일/1일 전 이메일 알림
- 사용완료 처리 (전역 상태 관리, 익명화 표시)

### 주요 의사결정 (DEC-1~6)

자세한 내용은 [프로젝트 개요](../project-overview.md) 참고

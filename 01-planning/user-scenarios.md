# 사용자 시나리오

## 시나리오 1: 엄마 (가족 공유형)

**시나리오명:** 엄마가 가족 쿠폰을 통합 관리하는 상황

**페르소나:** 엄마, 50대, 스마트폰 중~초급 사용자

**상황(Context):**
가족이 받은 쿠폰이 어디 있는지 불명확하고, 만료일이 지나 버려지는 일이 빈번. 가족끼리 공유할 수 있는 서비스 필요

**시나리오 흐름:**

1. 본인이 카톡으로 초대 링크 전송
2. 엄마가 링크 클릭 → 카카오 로그인 → 개인 스페이스 자동 생성 → '가족' 스페이스 입장신청 확인 (DEC-6)
3. 본인이 신청 승인 → 정식 멤버
4. 엄마가 '쿠폰 추가' → 쿠폰 사진 업로드 (만료일: 2026-12-31)
5. 쿠폰 목록 조회 → 만료순 정렬되어 있어 만료 전 쿠폰 확인
6. 만료 7일 전 이메일 받아 만료 전 쿠폰 정보 확인
7. 사용 후 '사용완료'

**기대 결과:**

- 가족 전체가 쿠폰의 위치 및 상태 파악 가능
- 만료 예정 쿠폰을 미리 알림받아 사용하지 못하는 손실 방지
- 중복 구매나 중복 사용 방지 (중복 업로드 문제는 추후 OCR로 해결)

## 시나리오 2: 직장인 (개인용)

**시나리오명:** 직장인이 받은 복지 쿠폰을 개인적으로 관리

**페르소나:** @@@, 30대, 직장인, 혼자만 서비스 사용

**상황(Context):**
회사에서 매달 복지 포인트로 쿠폰을 받는데, 어디 뒀는지 까먹고 만료. 개인적으로 받은 식사권/영화표/카페 쿠폰들을 한 곳에서 관리하고 싶음

**시나리오 흐름:**

1. 서비스 가입 → 개인 스페이스 자동 생성
2. 회사에서 받은 쿠폰 추가 (만료일: 2026-08-30)
3. 매달 받는 영화표 쿠폰 5개 일괄 추가
4. 식사권 2개 추가
5. 목록에서 만료순 정렬 조회 → 만료 임박 쿠폰 확인
6. 만료 7일 전 이메일로 쿠폰 정보 확인
7. 점심시간에 쿠폰 확인 후 바로 사용
8. 사용 후 '사용완료' 처리

**기대 결과:**

- 개인 쿠폰을 한곳에서 관리해 만료 손실 방지
- 바쁜 직장인도 간편하게 사용 가능
- 매달 자동으로 누적되는 쿠폰 현황 파악
